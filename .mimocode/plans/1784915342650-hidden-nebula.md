# 前端现代玻璃视觉统一 · 实施计划

## 背景

毛玻璃（backdrop-filter blur）壳层已合入，但用户反馈文字在玻璃背景上对比不足；按钮、面板、输入框等方块样式零散未统一。要求：现代统一视觉、NF 字体、无 emoji。

## 范围

- **视觉层**：文字对比度 + 字体角色 + 面板/输入/按钮统一样式
- **组件层**：修改既有 UI 组件，增补 Input 组件
- **Shell**：header/admin sidebar 文字对比，footer 回归文档流
- **字体**：MapleMono-NF-CN 本地打包，用于标题/数据/按钮
- **不涉及**：新增页面、替换 API client、修改后端、引入 UI 库

## 1. 视觉 Token（globals.css 增量）

```css
/* 文字层级 */
--text-display:  #0f172a;   /* H1/H2 */
--text-body:     #1e293b;   /* 正文 */
--text-secondary:#64748b;   /* 辅助 */
--text-inverse:  #f1f5f9;   /* 深色背景上 */
--text-inverse-muted: #94a3b8;

/* 玻璃面（面板/输入/侧栏统一）*/
--glass-panel:   rgba(255,255,255,0.65);
--glass-border:  rgba(0,0,0,0.06);
--glass-shadow:  0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.02);
--glass-radius:  0.625rem;

/* 字体 role */
--font-display: 'MapleMono NF CN', 'Inter', 'Noto Sans SC', system-ui, sans-serif;
--font-body:    'Inter', 'Noto Sans SC', 'Microsoft YaHei', system-ui, sans-serif;
--font-mono:    'MapleMono NF CN', 'SFMono-Regular', Consolas, monospace;
```

现有 `--foreground`/`--muted`/`--surface`/`--border` 继续保留，页面已有代码不破碎。

## 2. 字体本地打包

### 操作步骤

1. `mkdir -p frontend/public/fonts`
2. 下载 zip → 解压 → 将 `MapleMono-NF-CN.woff2`（或 `.ttf`）放入 `public/fonts/`
3. `globals.css` 添加：

```css
@font-face {
  font-family: 'MapleMono NF CN';
  src: url('/fonts/MapleMono-NF-CN.woff2') format('woff2'),
       url('/fonts/MapleMono-NF-CN.ttf') format('truetype');
  font-weight: 400 700;
  font-style: normal;
  font-display: swap;
  unicode-range: U+0020-2BFF, U+3000-303F, U+4E00-9FFF, U+FF00-FFEF;
}
```

### 风险与控制

- **体积**：如果下载为 ttf（~15MB），用 `woff2` 压缩（~5-7MB）。Docker 构建时将 `public/` 复制进最终镜像（Dockerfile 第 11 行已复制 `public`）。
- **fallback**：`font-family` 中始终包含系统回退，`font-display: swap` 确保渲染不被阻塞。
- **许可证**：Maple Mono 使用 OFL 许可证，MIT 项目可以自由包含。

## 3. UI 组件变动

### Button（button.tsx — 修改）

| 改动 | 说明 |
|---|---|
| **primary** 增加 `tracking-wide font-display` | 所有主按钮使用 Maple Mono 字族 + 字号距 |
| **secondary** 增加 `glass` 类 | 从 `border bg-surface` → `glass bg-white/65` |
| **ghost** 增加 `glass hover:bg-white/40` | 保持透明感 |
| **danger** 改为 `font-display tracking-wide` | 统一 |
| `transition` 增加 `duration-150` | 更现代响应 |

### Badge（badge.tsx — 修改）

所有 tone 改用 `bg-*-50` → `glass bg-*-/10 text-*-700` 半透明，如：
```ts
danger:  'glass bg-danger/10 text-danger'
success: 'glass bg-success/10 text-success'
warning: 'glass bg-warning/10 text-warning'
neutral: 'glass bg-foreground/5 text-secondary'
```

### Panel（panel.tsx — 修改）

```tsx
className = `rounded border border-black/5 bg-white/65 p-6 shadow-sm glass ${className}`
```
- 移除 `bg-surface`，改用半透明 `bg-white/65` + `glass`，透过面板看到背景底色。

### Alert（alert.tsx — 修改）

所有 tone 改用半透明背景 + `glass`：
```ts
danger:  'border-danger/20 bg-danger/5 text-danger glass'
success: 'border-success/20 bg-success/5 text-success glass'
warning: 'border-warning/20 bg-warning/5 text-warning glass'
```

### ErrorState / EmptyState / LoadingState（修改）

- ErrorState：`bg-red-50` → `glass bg-danger/5`
- EmptyState：`bg-background border-dashed` → `glass bg-foreground/[0.02] border-dashed border-foreground/10`
- LoadingState：不变

### **新组件：Input**（components/ui/input.tsx）

封装 `<input>`、`<select>`、`<textarea>` 的统一 API：

```tsx
export function Input(props: InputHTMLAttributes<HTMLInputElement>)
export function Select(props: SelectHTMLAttributes<HTMLSelectElement>)
export function Textarea(props: TextareaHTMLAttributes<HTMLTextAreaElement>)
```

统一 className：
```ts
'w-full rounded min-h-touch border border-black/10 bg-white/60 px-3 py-2 text-sm text-body glass placeholder:text-secondary transition disabled:opacity-50 focus-visible:outline-2 focus-visible:outline-focus'
```

改动量：替换 `frontend/app/` 下约 51 处原生 `<input>`/`<select>`/`<textarea>`。每次替换纯文本，无逻辑变更。

### **新组件：Table**（components/ui/table.tsx）

```tsx
export function Table({ children, ...props }: TableHTMLAttributes<HTMLTableElement>)
// 返回 <table className="w-full text-sm text-body" ... />
export function Th({ children, ... }: ThHTMLAttributes<HTMLTableCellElement>)
// 返回 <th className="px-4 py-3 text-left text-secondary text-xs font-medium uppercase tracking-wide" ... />
export function Td({ children, ... }: TdHTMLAttributes<HTMLTableCellElement>)
// 返回 <td className="px-4 py-3 border-t border-black/5" ... />
```

替换约 10 处 `<table>` 里面的 `<th>`/`<td>` 硬编码样式。**注意**：`<table>` 本身 `min-w-[36rem]` / `min-w-[48rem]` 等宽度在替换时单独保留，不作为默认值。

## 7. 风险和避免

| 风险 | 避免策略 |
|---|---|
| 字体 zip 含多种格式或不含 woff2 | 先 `unzip -l` 检查，优先取 woff2；仅 ttf 也无妨，`font-display: swap` 保证分阶段加载 |
| woff2 在 Docker Alpine 构建时兼容 | Node 18 不含字体处理工具；字体只是静态文件，build 阶段只 `COPY public/`，不需处理 |
| panel 半透明背景 → 内容透底 → 可读问题 | `bg-white/65` 保证 65% 不透明 + 背景色 `#F6F8FA` 足够提供对比，正文 4.5:1+ |
| Input 组件替换遗漏 | grep 清单已枚举 51 处，逐文件替换后用 `grep -c '<input\|<select\|<textarea'` 验证 |
| Badge/Button 半透明 → 基线颜色偏移 | 在 Chrome 中截图对比色值，确保 `text-danger` 等 token 不变 |
